# Mobile App Redesign Case Study

## Project Overview
This project focused on improving the overall navigation, accessibility, and visual coherence of our flagship mobile application. By utilizing key user research methodologies and iterative prototyping, we saw a significant increase in user engagement and satisfaction.

## Key Challenges
- Outdated visual style guide
- High drop-off rate at user onboarding
- Inconsistent interactive components

## Solutions & Impact
- Designed a unified system-wide UI design token system.
- Simplified the user onboarding flow from 7 steps to 3 steps.
- Improved accessibility compliance to WCAG AA standards.
